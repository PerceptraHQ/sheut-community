# Support

Sheut is in active foundation development and is not ready for operational
intelligence.

- Use GitHub Issues for reproducible Community bugs and focused feature
  proposals.
- Use a private GitHub security advisory for vulnerabilities.
- Do not post real intelligence, credentials, personal data, or customer
  material.
- Enterprise support and service-level commitments are not provided from this
  Community repository.

Questions should include the operating system, Sheut version or commit, exact
steps, expected behavior, and sanitized diagnostics.
